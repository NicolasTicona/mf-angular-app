Architecture
System overview
Composition
Vite manifest + DOM injection

1 · Manifest fetch

On button click, Angular fetches .vite/manifest.json from the React origin. Cache strategy is no-store locally and no-cache (ETag) on deployed envs.

2 · Script injection

The manifest maps index.html → hashed JS + CSS filenames. Angular creates <script type="module"> and <link rel="stylesheet"> and appends them to <head>.

3 · MICROFRONTEND_LOADED

React's main.jsx runs, detects hosted mode (isBootstrap = false), and dispatches this event. Angular was already listening with { once: true }.

4 · MICROFRONTEND_RENDER

Angular replies with this event carrying the container HTMLElement. React calls createRoot(detail.nodeToLoadIn).render(<App />). Chat overlay is live.

No Webpack Module Federation. No shared module negotiation. Each app bundles its own dependencies. The only contract is the event protocol and the manifest format.

Host
manifest fetch + script injection
// src/app/utils/microfrontend.util.ts
async function loadViteMicrofrontend(
  microfrontend: Microfrontend,
  nodeToLoadIn: HTMLElement
) {
  const response = await fetch(
    microfrontend.manifestPath,
    { cache: microfrontend.cacheStrategy ?? 'no-store' }
  );
  const manifest = await response.json();

  window.addEventListener('MICROFRONTEND_LOADED', (event: Event) => {
    const ce = event as CustomEvent;
    if (ce.detail.name === microfrontend.name) {
      window.dispatchEvent(new CustomEvent('MICROFRONTEND_RENDER', {
        detail: { nodeToLoadIn, name: microfrontend.name }
      }));
    }
  });

  const index = manifest['index.html'];
  const script = document.createElement('script');
  script.src = `${microfrontend.origin}/${index.file}`;
  script.type = 'module';
  const css = document.createElement('link');
  css.rel = 'stylesheet';
  css.href = `${microfrontend.origin}/${index.css[0]}`;
  document.head.appendChild(script);
  document.head.appendChild(css);
}

// mf-react-app/src/constants/app.constants.js
const whiteListBootstrap = ['http://localhost:3000', 'http://127.0.0.1:8080'];

export const isBootstrap =
  whiteListBootstrap.includes(window.location.origin) ||
  window.location.pathname.startsWith('/mf-react-app');
// pathname check handles GitHub Pages shared origin
Integration layer
React entry — hosted vs standalone
// mf-react-app/src/main.jsx
import { isBootstrap } from './constants/app.constants.js';

if (isBootstrap) {
  // standalone: mount into static #react-root in index.html
  createRoot(document.getElementById("react-root"))
    .render();
} else {
  // hosted: wait for Angular to provide container node
  window.addEventListener("MICROFRONTEND_RENDER", ({ detail }) => {
    if (detail.name === "react-app") {
      createRoot(detail.nodeToLoadIn)
        .render();
    }
  });

  // signal Angular that scripts are loaded
  window.dispatchEvent(
    new CustomEvent("MICROFRONTEND_LOADED", {
      detail: { name: "react-app" }
    })
  );
}

      type: 'card',

Angular listeners wrap callbacks in this.zone.run(() => { … }) — required because native window.addEventListener runs outside Angular's zone and won't trigger change detection otherwise.
Extensibility
Adding a new remote
1
Build remote with build.manifest: true in vite.config.js. Confirm .vite/manifest.json is produced in dist/
2
Add remote name to allowedMicrofrontendNames in src/app/utils/microfrontend.util.ts
3
Add environment entry in all four env files (environment.ts, environment.local.ts, environment.development.ts, environment.production.ts) — set origin, manifestPath, buildType: 'vite', and cacheStrategy for deployed envs
4
Create host component with @ViewChild container. On trigger, call loadMicrofrontend('<name>', containerEl)
5
In remote main.jsx: check isBootstrap; in hosted path dispatch MICROFRONTEND_LOADED and listen for MICROFRONTEND_RENDER
6
Add new remote origin to isBootstrap whitelist in the remote's app.constants.js (local port) and pathname check if deployed to a sub-path
7
Naming invariant: the string must match across environment.microfrontends['<name>'] key, allowedMicrofrontendNames, MICROFRONTEND_LOADED detail.name, and MICROFRONTEND_RENDER detail.name check

Build tool for mf-react-app. build.manifest: true produces .vite/manifest.json — the file Angular reads at runtime to find hashed entry assets.

@vitejs/plugin-react@4.3.3

Vite plugin providing React fast refresh and automatic JSX transform for mf-react-app.

@angular/core@16.2.x

Angular 16 framework for the shell. Standalone components pattern used throughout — no feature NgModules.

Angular change detection. NgZone.run() is required when handling native DOM CustomEvent callbacks to trigger Angular's update cycle.

Serves dist/ locally for preview mode in both apps. The Angular host fetches the React manifest from the running http-server instance.

Angular CLI build system. Three named configurations: local (default), development, production — each pointing to a different React MFE origin.
